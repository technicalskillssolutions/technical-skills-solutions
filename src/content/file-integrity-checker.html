What is a file hash?

A hash is a fixed-length digital fingerprint calculated from file contents. If even a small part of a file changes, its hash will normally change too. Matching a trusted SHA-256 checksum helps verify that a downloaded file has not changed unexpectedly. A hash alone does not prove that a file is safe or free of malware.
