Android & TalkBack

A mobile-first guide to using Technical Skills Solutions with TalkBack, touch navigation and an installable home-screen app.

DESIGNED FOR ANDROID

Use the portal like an app

This website adjusts its navigation for Android, uses large touch targets and announces important status changes. You can install it from Chrome on Android so it opens from your home screen like a web app.

On Android Chrome, use the browser menu and choose Install app if the install button is not available.

TALKBACK QUICK NAVIGATION

Essential gestures

  • Next item: swipe right with one finger.
  • Previous item: swipe left with one finger.
  • Activate: touch an item, then double-tap anywhere.
  • Scroll: swipe with two fingers.
  • Explore by touch: move one finger around the screen to hear items.
  • TalkBack menu: swipe down then right, or use a three-finger tap on supported devices.

Gestures can vary by TalkBack version, Android version and device manufacturer. Follow the official TalkBack guide for your device.

Install from Chrome on Android

  1. Open this website in Google Chrome on your Android phone.
  2. Open Chrome's three-dot menu.
  3. Choose Install app or Add to Home screen, depending on the Chrome version and the device.
  4. Confirm the installation. The site icon will appear on your home screen or app launcher.

The install option is available when the site is served over HTTPS. Some features still need an internet connection, including OCR language-data downloads and external provider tools.
