PRIVACY TOOL

Temporary Mail Inbox

Create a disposable receive-only email address, read incoming messages as plain text, and copy possible one-time codes.

Low-risk testing only. Do not use temporary addresses for banking, government services, password recovery, work accounts, private conversations or accounts you need to keep. Inbox availability and retention are controlled by the email provider; do not assume a fixed expiry time.

Create a temporary inbox

The inbox is created directly through a public temporary-email API. The page first tries Mail.tm and, only if that service cannot be reached, tries Mail.gw. No name, personal contact email or phone number is requested. A random account password and access token are generated for the inbox and kept in this browser tab only. The selected email provider receives the API requests and stores incoming messages according to its service rules.

No temporary inbox has been created in this tab.

Inbox retention is controlled by the email provider.

No messages loaded.

This website talks directly to the selected provider API; it does not proxy email traffic through the website server. Both documented providers offer public APIs without an API key and enforce per-IP rate limits. The temporary account password is not displayed; its access token is kept in session storage and cleared when you forget the inbox or close the tab. A temporary inbox is not private or reliable storage.
